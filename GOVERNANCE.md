# Governance

Morphology Studio currently uses a single-maintainer model. The repository owner has merge, release, and security-response authority. Contributors propose changes through issues and pull requests; decisions prioritize safety, robot-agnostic design, test evidence, compatibility, and maintainability.

Regular contributors may receive triage or review responsibilities after sustained, constructive participation. Additional maintainers require demonstrated judgment and explicit approval from the repository owner. If the community grows, this document will be revised through a reviewed pull request to define voting, succession, and conflict-resolution rules.
