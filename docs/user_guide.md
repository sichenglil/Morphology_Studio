# User guide

The normal sequence is import, inspect, pose, edit, assemble, validate, then export. The left sidebar shows the model hierarchy and resources, the center viewport handles selection and gizmos, the right inspector edits exact properties, and the bottom dock controls joints and validation messages.

Keyboard shortcuts: `W` move, `E` rotate, `R` scale eligible geometry, `X` change coordinate space, `F` focus, `Q` or `Esc` clear/cancel, and `Ctrl+Z`/`Ctrl+Y` undo/redo.
