# Getting started

Install Python 3.9–3.13, Node 20–24, pnpm 10–11, and Git. On Windows run `./scripts/setup_dev.ps1`; on Linux/macOS run `./scripts/setup_dev.sh`. Start the Windows desktop with `python desktop_entry.py`, or start the API with `./scripts/run_web.ps1` and Vite with `pnpm --dir web/frontend dev`.

Import `assets/robot_models/ur5e_hx5_right/robot.urdf` for a dependency-free first run. Source files are read-only; choose a separate output location.
