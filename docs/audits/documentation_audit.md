# Documentation audit

The original README described features but was Chinese-only, included a workstation path, lacked status tables and a reproducible generic first run, and had no documentation site. Historical feature audits remain useful maintainer evidence but are not the primary user journey.

The new English and Chinese README pair, MkDocs navigation, workflow guides, support policy, and link tests provide a coherent entry path. Application screenshots must be regenerated from the generic two-link example whenever the UI changes.
