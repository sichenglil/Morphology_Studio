# Open-source readiness

The repository now has an Apache-2.0 license, notices, governance and security policies, contribution templates, CI definitions, generic fixtures, bilingual entry documentation, and local health checks. Visibility remains private during preparation.

Known limits: ROS 2, Isaac Sim, and Isaac Lab are `NOT_AVAILABLE_LOCAL`; USD is not locally validated; MJCF and Xacro are Beta; formal public release has not occurred. REUSE lint and all runtime/build checks must be reported from actual commands. Public visibility is a separate owner decision after reviewing history, screenshots, CI results, and GitHub security settings.
