# Visual tutorial

All images below were captured by Playwright from the current application using `examples/simple_two_link/robot.urdf`.

1. Open the generic model in the import dialog. ![Import dialog with generic URDF path](assets/screenshots/import-dialog.png)
2. Confirm the model tree and 3D geometry. ![Imported two-link robot](assets/screenshots/model-imported.png)
3. Select the arm link. ![Selected arm link](assets/screenshots/link-selected.png)
4. Switch to the rotate gizmo. ![Rotate gizmo around the selected link](assets/screenshots/rotate-gizmo.png)
5. Enter an exact joint value. ![Joint slider and numeric control](assets/screenshots/joint-control.png)
6. Inspect the exact transform. ![Transform inspector](assets/screenshots/transform-inspector.png)
7. Browse resolved resources. ![Resource panel](assets/screenshots/resources-panel.png)
8. Open the assembly workflow. ![Assembly dialog](assets/screenshots/assembly-dialog.png)
9. Run validation. ![Validation results](assets/screenshots/validation-results.png)
10. Choose an export format and destination. ![Export dialog](assets/screenshots/export-dialog.png)

The short [animated workflow](assets/demo/workflow.webp) is generated from the same capture sequence.
