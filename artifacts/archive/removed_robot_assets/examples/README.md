# Generic examples

These Apache-2.0 examples use URDF primitives, require no ROS or Isaac installation, and are safe for tests and screenshots. In Morphology Studio choose **Import model** and open `simple_two_link/robot.urdf`, `simple_tool/tool.urdf`, or `simple_camera/camera.urdf`. Assemble the tool or camera onto a selected link with a fixed joint. Generated output belongs outside this directory.
