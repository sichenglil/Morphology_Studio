# Support

Use the bug template for reproducible defects, feature template for proposals, and documentation template for unclear guidance. Include the version, OS, Python/Node versions, launch mode, model format, reproduction steps, and sanitized logs. Usage questions may use GitHub Discussions if enabled; otherwise open a documentation issue.

Security reports follow [SECURITY.md](SECURITY.md). Do not upload confidential robot models, tokens, private paths, or credentials. Maintainers cannot provide proprietary CAD repair, remote ROS/Isaac administration, guaranteed conversion fidelity for every vendor extension, or private consulting through the issue tracker.
